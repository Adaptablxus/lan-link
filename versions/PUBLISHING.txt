=========================================================
4. MODRINTH  (modrinth.com)
=========================================================
1. Sign in, then: avatar menu -> "Create a project" -> type: Mod.
2. Name: LAN Link.  Slug: lan-link.
   Summary + description: from section 1 (README.md).
3. Upload the icon; set License: MIT.
   Environments: Client = Required, Server = Unsupported.
4. "Versions" -> Create version:
     file            versions\1.0.1\lan-link-1.0.1.jar
     version number  1.0.1
     channel         Release
     game version    26.2
     loader          Fabric
     dependencies    none
   Paste the 1.0.1 changelog.
5. Create a second version the same way for 1.0.0 (+ its changelog).
6. Publish.


=========================================================
5. CURSEFORGE  (curseforge.com)
=========================================================
1. Sign in -> Author Dashboard -> "Create Project" -> Minecraft -> Mods.
2. Name/summary/description (README.md), main category e.g.
   "Utility & QoL"; upload the 400x400 icon.
3. Project settings: Game version 26.2, Mod loader Fabric,
   side: Client, license MIT.
4. Files -> "Upload File":
     versions\1.0.1\lan-link-1.0.1.jar -> Release type: Release,
     game version 26.2, no dependencies.  (+ changelog)
   Repeat for 1.0.0.
5. Note: new CurseForge projects are reviewed before they appear in
   search / allow downloads - upload early so the review runs.

6. GITHUB  (github.com)
=========================================================
DONE (2026-10-15) - repo is live:
    https://github.com/Adaptablxus/lan-link
main = "LAN Link 1.0.1"; Releases v1.0.0 + v1.0.1 both carry
their jars; the Action builds on every push. (To push again:
personal access token + clean remote URL; never store the token.)

Repo notes:
 - .gitignore is ready: .gradle/, build/, run/, IDE files and the
   local test tooling (tools/) are excluded. tools/ holds the portable
   Prism launcher + JDKs (hundreds of MB) - never commit it.
 - libs/ MUST stay committed: quiclime-codec-*.jar is a real build
   dependency.
 - .github/workflows/build.yml already exists - GitHub builds the mod
   automatically on every push (see the run's Artifacts).
 - Releases (recommended place for the jars):
   Releases -> "Draft a new release"
     tag: v1.0.1   title: LAN Link 1.0.1
     attach versions\1.0.1\lan-link-1.0.1.jar + changelog
   Repeat with tag v1.0.0.
 - Optional: if you want a smaller repo, add `versions/` to .gitignore
   and keep the jars only in GitHub Releases.
 - Put the repo URL into the "Source" field of the Modrinth and
   CurseForge pages.
